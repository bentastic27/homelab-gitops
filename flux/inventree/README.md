# InvenTree

Deployed from the official chart (`inventree/helm-charts`) at https://inventree.int.beansnet.net (internal gateway only).

## Admin login

The initial superuser is seeded on first boot from the `inventree-admin` secret
(the password is generated by kubernetes-secret-generator). Changing the password
in the app later does not update the secret.

Username:

```bash
kubectl -n inventree get secret inventree-admin -o jsonpath='{.data.INVENTREE_ADMIN_USER}' | base64 -d; echo
```

Password:

```bash
kubectl -n inventree get secret inventree-admin -o jsonpath='{.data.INVENTREE_ADMIN_PASSWORD}' | base64 -d; echo
```
